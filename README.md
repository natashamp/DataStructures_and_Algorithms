# Data Structures and Algorithms
 Data Structures and Algorithms CS 146 F22

Written in Eclipse 




### Project #2) Maximum Subarray 

Implement, optimize, and analyze three different algorithms to solve the Maximum Subarray Problem, which finds the subarray with the largest sum in a given array.


### Project #3) BFS & DFS: Maze Generation and Solving 

This project focuses on automatically generating and solving mazes using Breadth-First Search (BFS) and Depth-First Search (DFS). The maze is represented as a graph, where each room is a vertex and removed walls form edges.


### Project #4) Red Black Tree: Dictionary and Spell Checker

This project involves implementing a Red Black Tree to store words from a dictionary file and use it for spell-checking a poem. The tree must support efficient insertion, lookup, and traversal while maintaining balance through rotations and tree-fixing methods.
